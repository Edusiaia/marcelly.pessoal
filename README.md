# Site — Marcelly Lemes

Site pessoal (portfólio) de Marcelly Lemes, focado em Gestão aplicada com
Inteligência Artificial.

## Estrutura

```
index.html      página principal
css/style.css   estilos
js/main.js      interações (menu, animações, acordeão do FAQ)
CAPA.jpeg       imagem de banner (seção Início / cards de projetos)
PERFIL.jpeg     foto de perfil (logo e seção Sobre)
```

Site estático, sem frameworks e sem etapa de build. Basta abrir
`index.html` no navegador ou publicar a pasta no GitHub Pages.

## Pendências antes de publicar

Procure por `[PREENCHER]` no `index.html` e substitua pelos dados reais:

- Texto da seção **Sobre** (formação, tempo de atuação, conquistas, números)
- Cards da seção **Projetos** (nome, descrição e resultado de cada case)
- Respostas de algumas perguntas do **FAQ**
- Contato: o WhatsApp e o e-mail atuais são **fictícios** — troque pelos reais
  em `index.html` (busque por `5519999999999` e `marcelly@lemes.com`)
